# 🧾 Retail Billing Management System

A **Full-Stack Retail Billing Management System** developed using **React.js and Spring Boot**.  
This application helps manage retail inventory by allowing users to organize products, manage categories, and upload product images through a responsive and dynamic web interface.

The project demonstrates **end-to-end full-stack development**, including REST API creation, database integration, file handling, and responsive frontend development.

---

## 🚀 Key Features

- 📦 Category Management (Add, View, Delete)
- 🛒 Product Management with Category Mapping
- 🖼️ Product Image Upload & Display
- 🔍 Product Search Functionality
- 🗑️ Delete Products and Categories
- ⚡ Dynamic UI with Real-Time Updates
- 📱 Responsive Design for multiple devices
- 🔗 RESTful API integration between frontend and backend

## 📂 Project Overview

The application follows a **client-server architecture**:

- **Frontend (React.js)** handles the user interface and communicates with backend APIs using Axios.
- **Backend (Spring Boot)** manages business logic, REST API endpoints, and database operations.
- **MySQL** stores product and category data.
- **Local File Storage** is used to store and retrieve uploaded product images.
